# 小程序隐私告知与协议确认

## 本次范围

- 商品列表和隐私、服务协议页面公开可读，无需绑定。
- 首次绑定的协议确认框默认不勾选；未确认或版本过期时，服务端拒绝绑定。
- 家庭地址为选填信息，其用途纳入微信绑定时统一确认的隐私指引；修改时显示用途提示，不再另设地址勾选框。用户主动填写并保存，不提供地址不影响注册、领券、下单和提货。
- 结算不再收集家庭地址，也不向到店提货订单复制资料中的家庭地址。
- 协议仅在微信绑定／重新绑定时确认；修改资料、结算不再重复确认。原有账号不回填或伪造同意记录，不因缺少历史确认记录阻断已有交易功能。
- “我的”提供隐私保护指引、用户服务协议、联系商家入口，默认商家电话 13324205796。
- 按本次用户要求，暂不开发自助注销、删除页面或商家审批流程。更正、复制、删除、注销、撤回同意等需求由商家电话受理，并依法处理；不是由商家自由决定是否批准。

## 部署

先运行 `cd backend && ../.venv/bin/alembic upgrade head`，再重启后端；新迁移为 `0010_privacy_controls`。
前端执行 `npm run build`。现有 `deploy/install.sh` 会运行迁移及构建。
小程序源码必须同步更新、重新编译，上传新版体验包或正式包；旧版不能提交新要求的协议确认字段。

## 运营设置

电脑后台 → 隐私与联系：

1. 将经营主体全称改为营业执照上的真实名称；初始值仅使用现有店铺名称“农丰水站”，不能视为已经核实主体。
2. 核对联系商家电话。其用于订单咨询和个人信息权利请求，请确保能接听、能跟进处理。
3. 可查看最近 100 条绑定确认或地址变更记录，显示客户编号、场景、服务器时间、地址保存状态及对应协议／指引原文。地址变更不表示用户重新接受了绑定协议。

指引正文由服务端维护，修改名称、电话或正文会根据实际内容生成新版本。每次确认同时保存不可变的协议原文存档和确认记录，不收集额外的 IP 或设备指纹。
确认时间用服务器 UTC 保存，接口返回带时区的时间，界面转换为设备本地时间。
不要直接修改或删除 `legal_documents`、`legal_consents` 来伪造确认记录。

## 用户撤回选填地址保存

“我的 → 修改资料”清空地址并保存，即清空账户当前地址、清除地址保存状态，并产生一条清空地址的记录。修改、保存或清空地址不改写绑定协议版本和确认时间。历史订单法定留存与账户地址清理是不同事项，应向用户说明。
本次不批量清理已有历史数据。上线前应按实际留存目的梳理旧订单地址、日志、备份的保留与删除制度。

## 微信平台配置仍需人工完成

本工程的业务告知和确认不代替微信公众平台的《小程序用户隐私保护指引》配置。
请按真实处理的数据填写微信身份标识、称呼、联系电话、选填地址、订单和优惠券等用途；以平台可选项目和实际接口为准。
若以后新增微信手机号获取、照片选择、定位等隐私相关接口，需同步更新告知文本、平台声明，并接入对应的微信授权流程。

本次未新增上述隐私接口，不会以“已勾选自有协议”为由伪造微信平台的授权状态。
备案、正式 HTTPS 域名及经营资质公示仍须按上线清单另行完成。

参考：《个人信息保护法》 https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm
