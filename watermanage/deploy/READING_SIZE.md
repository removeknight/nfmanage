# 小程序字体大小

入口：小程序「我的 → 字体大小」，无需登录也可以设置。

| 选项 | 效果 |
| --- | --- |
| 跟随微信（默认） | 按微信客户端的字号设置调整 |
| 小号 | 在标准基础上缩小 12.5% |
| 标准 | 使用更新后的清晰默认字号 |
| 大号 | 在标准基础上放大 20% |
| 特大 | 在标准基础上放大 40% |

选择后即时更新已打开的客户页面、表单和商家工作台，并在本机保存。手动选择的档位优先，不再叠加微信字号倍率。切换到跟随微信后，重新进入小程序时读取微信最新字号；旧客户端缺少相关参数时使用标准字号。

页面使用 page-meta 设置 rem 根字号。现有页面的进入逻辑由 utils/reading.js 的 readingPage 包装，保留原有轮询和权限检查。新增页面也应使用该包装，并在 WXML 顶部放置 page-meta，正文字号使用 rem。

商品价格与数量区、结算条、订单操作、优惠券及商家列表采用可换行布局。加减数量的点击区域保持至少 44×44 CSS 像素；表单高度跟随字号调整。微信原生导航栏、底部标签栏和系统弹窗由微信客户端控制。

该功能为小程序客户端改动，无需数据库迁移或修改服务器环境变量。服务器拉取 Git 只同步源码；开发者工具需重新编译并生成新的真机调试码。体验版需上传新代码包并设为体验版，正式版需按微信审核发布流程更新。
