# 商家权限

| 身份 | 小程序经营功能 | 电脑后台 | 授权范围 |
| --- | --- | --- | --- |
| 店主 | 全部 | 全部 | 副店长、店员 |
| 副店长 | 与店主相同 | 与店主相同 | 仅店员 |
| 店员 | 查单、提货核销、查看库存 | 不可登录 | 无 |
| 普通客户 | 下单、查看个人订单和优惠券 | 不可登录 | 无 |

## 首位店主

先用指定微信账号绑定小程序。在应用服务器的项目目录执行：

```bash
cd /opt/nfmanage/watermanage
bash deploy/merchant-bootstrap.sh
bash deploy/merchant-bootstrap.sh --customer-id 客户ID
```

第一条工具命令仅列出当前登录环境的已绑定客户；核对后用真实客户 ID 替换占位文字执行第二条。已有店主时工具拒绝再次初始化，不会自动选择第一个客户。现有店主权限保留。

## 授权副店长和店员

店主在小程序「我的 → 商家工作台」生成电脑登录码，登录电脑后台。在「客户管理」找到已绑定的小程序客户，点击「设置权限」，选择副店长、店员或普通客户（停用商家权限）。副店长只能调整店员和普通客户，不能调整自己、其他副店长或店主。

普通客户的小程序中不显示商家授权入口，旧的授权码页面及兑换入口已关闭。授权绑定数据库中的微信身份，不依赖填写的姓名或手机号。线下电脑录入客户及其他 AppID、模拟登录环境的客户不可被授权。

授权后客户进入「我的」即可看到工作台，页面可见时也会自动同步。降级或停用会撤销该账号旧的电脑会话及未使用的电脑登录码，小程序会话保留以继续作为客户使用。所有商家接口实时校验数据库角色，并记录权限调整日志。

本次角色扩展使用现有 merchant_members.role 字段，无需数据库结构迁移。更新服务端和网页后，小程序需重新编译并重新生成真机调试码。
